# Glow Beauty - Premium Skincare Website
#Live link- https://gowri0824.github.io/intern-tasks-1/

This project is a responsive 3-page website built using **Bootstrap 5**, HTML5, and CSS3. It demonstrates a premium skincare brand with a modern and elegant design.

## Folder Structure
- `index.html`: Home page with Hero, Features, and Footer.
- `about.html`: About page with Story, Services, and Statistics.
- `contact.html`: Contact page with a working form and validation.
- `css/style.css`: Custom styles overrides and theme definitions.
- `images/`: Contains generated assets for the project.

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5 (CDN)
- JavaScript (for form validation and modals)
- AOS Animation Library

## How to Run
1. Clone the repository.
2. Open `index.html` in your browser.
